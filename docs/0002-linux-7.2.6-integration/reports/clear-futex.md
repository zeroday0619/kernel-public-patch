# Clear Linux and legacy fsync port to Linux 7.2.6

The two input patch files were inspected against the current source. None of the six Clear Linux changes or legacy opcode 31 support was already present. All seven functional changes were ported and applied. No build, configuration, install, boot, or runtime test was performed.

## Corrections to the supplied opcode 31 patch

- Allocate and copy before initializing the on-stack timer, so EFAULT/ENOMEM/EINVAL paths cannot leak an initialized timer.
- Use futex_to_flags() internal FLAGS_SIZE_32/shared-private flags rather than the UAPI FUTEX_32 constant, which is not the current internal flag representation.
- Preserve private/shared selection from the operation.
- Decode compatibility entries with compat_uptr_t and compat_ptr rather than interpreting 32-bit arrays as native pointer-sized arrays.
- Initialize queues from futex_q_init and set the current wake callback.
- Preserve the supplied patch's ignored bitset/MATCH_ANY behavior, including acceptance of zero or uninitialized legacy bitset fields.
- Validate realtime/robust operation modifiers through current do_futex; the legacy relative timeout uses CLOCK_MONOTONIC.
- Bound allocation to 1..FUTEX_WAITV_MAX and free waiters on every exit.
- Cancel and destroy the on-stack timer after every wait result.
- Return EINTR for interrupted timed waits so SA_RESTART cannot reset a relative timeout and extend its deadline. Untimed waits retain ERESTARTSYS.
